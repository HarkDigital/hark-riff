# Hark Riff — concept site

A Hark Digital concept direction, built from `Hark Concept Starter`
(see `../HARK-CONCEPT-PLAYBOOK.md`): a rock stage between songs, with one
sunburst single-cut guitar at the heart of it — flame maple that shimmers
as the camera moves, strings that really ring, tube amps, a pedalboard, and a
speaker-cab cut between chapters (the frame thumps like a cone and grille
cloth closes over it).

**Live:** https://harkdigital.github.io/hark-riff/

```bash
npm install
npm run dev
npm run build
```

Kit (`src/kit/`): `guitar.ts` (the instrument), `strings.ts` (vibrating
strings + `Ring`), `amp.ts` (heads, combos, 4x12 cabs), `stage.ts` (floor,
cables, gaffer, pedals), `materials.ts` (nickel, rosewood, pearl, tolex,
grille cloth, fonts), `pace.ts` (StoryClock). Look lab: `?lab&view=stand|top|macro`.
